## 2026-10-24 - Provider requests carry the session working directory (senpi#2848)

### What changed

- `packages/ai/src/types.ts`: provider request options accept the originating session's `cwd` for subprocess-backed providers.

### Why

- `packages/ai/src/types.ts`: a shared engine process can serve projects outside its process working directory; subprocess adapters need the session directory rather than the host directory.

### Why an extension could not handle it

- `packages/ai/src/types.ts`: this option crosses the shared provider request contract before an adapter is selected.

### Expected merge conflict zones

- `packages/ai/src/types.ts`: the optional fields at the start of `ProviderRequestOptions`.

## 2026-10-24 - Session factories forward their cwd to provider requests (senpi#2848)

### What changed

- `packages/coding-agent/src/core/sdk.ts`: the session's provider stream wrapper passes its resolved `cwd` alongside request options.

### Why

- `packages/coding-agent/src/core/sdk.ts`: CLI and hosted desktop sessions already resolve a project directory, but the provider boundary discarded it, so SDK children used the shared process directory instead.

### Why an extension could not handle it

- `packages/coding-agent/src/core/sdk.ts`: the shared session factory owns the resolved directory and constructs the provider request.

### Expected merge conflict zones

- `packages/coding-agent/src/core/sdk.ts`: the `modelRuntime.streamSimple` options object.

## 2026-10-24 - Claude SDK requests use their session project (senpi#2848)

### What changed

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/stream.ts`: both resident and auxiliary requests resolve provider settings and SDK query cwd from the originating session; low-level callers without a cwd retain the process-directory default.

### Why

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/stream.ts`: the host directory could select another project's Claude Code memory and disagree with the session's compaction-owner policy. Reported by @jaeheungahn in code-yeongyu/oh-my-openagent#11189.

### Why an extension could not handle it

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/stream.ts`: this is the bundled SDK adapter's own query-options construction.

### Expected merge conflict zones

- `packages/coding-agent/src/core/extensions/builtin/anthropic-subscription/stream.ts`: provider settings resolution and `buildAnthropicSubscriptionQueryOptions` arguments.
